# Airport layout data

The files in this folder (`<ICAO>.json`) are extracts of OpenStreetMap:
**© OpenStreetMap contributors**, available under the
[Open Data Commons Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
See https://www.openstreetmap.org/copyright.

They were downloaded with `tools/fetch_osm.py` (Overpass API). The game's
airport files derived from them (`data/airports-hq/`) are likewise available
under the ODbL. The rest of the game is not affected by this licence.

OpenStreetMap is not an aeronautical source: layouts can be out of date or
incomplete. Not for real-world navigation.
